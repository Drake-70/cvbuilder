% Build-time warm-up for the tectonic bundle cache. Never rendered, never served.
%
% This document's only job is to make tectonic fetch every package that the CV
% templates need, at image build time instead of during a user's first export.
% Each \usepackage below appears in latexService.js for the same reason -- if a
% package is added to a template without being added here, the first CV that needs
% it will try to reach the network, and the runtime runs with --only-cached, so it
% will fall over to pdfkit instead of hanging.
%
% Constraints discovered by probing tectonic 0.17.0's bundle, which is a reduced
% TeX Live. Keep this in step with latexService.js:
%
%   * helvet, tgheros and newtxsf are NOT in the bundle, and fontspec by font
%     *name* additionally needs fontconfig. So every template is serif and uses
%     newtxtext.
%   * T1 encoding alone needs the EC font metrics, which are absent, and fails
%     with a fontconfig error. newtxtext in the same preamble supplies them, so
%     fontenc and newtxtext always travel together.
%   * Nothing here may enter math mode. The Computer Modern maths fonts (cmsy,
%     cmmi) are absent too, so a single $...$ fails at the xdvipdfmx stage with
%     "Cannot proceed without .vf or physical font for PDF output".
